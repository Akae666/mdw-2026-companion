这台设备里的记录

这个网站现在把打卡、错过、reflection 和照片存在当前设备的当前浏览器里。换设备前先导出，在新设备上再导入。

1. 电脑导出在电脑打开这个页面，点“一键导出记录包”。
2. 发到手机用 AirDrop、iCloud Drive、微信文件或邮件把 JSON 发到手机。
3. 手机导入手机打开线上网页，点“一键导入记录包”。
4. 最终打包看完展后，在手机上再导出一次，就是最终 memory pack。

Safety note

本地储存说明

GitHub Pages 只负责发布网页，不会自动同步你的私人记录。导出 JSON 里会包含压缩后的照片，所以最终文件可能会随着照片数量变大。
